# 🛒 Blinkit Retail Performance Dashboard

An end-to-end Power BI analysis architected to audit **$1.20M in retail revenue** across **9,000+ inventory items**, uncovering which outlet tiers, establishment types, and product categories actually drive performance — and which are quietly underperforming their shelf space.


---

## 📌 Project Overview

Raw outlet and item-level sales data rarely explains itself. This project builds a fully interactive Power BI dashboard that goes beyond flat totals to isolate the real revenue drivers behind Blinkit's retail network — comparing performance across Grocery Stores and Supermarket Types 1–3, outlet sizes, location tiers, and item categories, then packaging the findings into a dynamic, decision-ready dashboard rather than a static report.

## 🧭 What the Dashboard Does

**Architected a $1.20M retail performance dashboard** to audit 9K+ inventory items, identifying key revenue drivers across multiple outlet tiers and establishment types — surfacing which combinations of outlet size, location, and item category actually convert into sales, rather than assuming size or location alone explains performance.

**Designed a dynamic matrix with heat-map–style conditional formatting** to compare Total Sales, Average Rating, and Item Visibility side by side across Grocery Store and Supermarket Type 1/2/3 outlets — turning a dense comparison table into something that can be scanned for outliers in seconds instead of read row by row.

**Applied area charts and proportion-based funnel visuals** to track sales trends across outlet establishment years and location distribution across Tier 1/2/3 — supporting strategic questions like where to expand next and how to allocate stock across outlet tiers based on demonstrated performance, not assumption.

## 📊 Dashboard Features

| Visual | Purpose |
|---|---|
| KPI Cards | Total Sales, Avg Sales, No. of Items, Avg Rating at a glance |
| Line/Area Chart | Sales trend across outlet establishment years |
| Donut Charts | Fat Content split, Outlet Size distribution |
| Heat-Mapped Matrix | Outlet Type × Total Sales / Avg Sales / Avg Rating / No. of Items / Sum of Item Visibility |
| Horizontal Bar Charts | Item Type and Fat-by-Outlet performance breakdowns |
| Funnel-style Tier Bars | Outlet Location distribution across Tier 1 / Tier 2 / Tier 3 |

## 🛠️ Tools & Techniques

- **Power BI Desktop** — report design, interactive visuals, page layout
- **DAX** — custom measures for Avg Sales, Avg Rating, and Item Visibility aggregations
- **Power Query** — data cleaning, type transformation, category standardization
- **Conditional Formatting** — heat-mapped matrix for cross-outlet comparison

## 🚀 How to Run

1. Download and install **Power BI Desktop** (free)
2. Open `Blinkit_Analysis.pbix`
3. If prompted, update the data source path to point to your local dataset folder
4. Refresh the data and explore the dashboard
